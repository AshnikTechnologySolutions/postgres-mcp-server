# Governance

## Project Steward

This project is owned and stewarded by **Ashnik Technology Solutions Pvt Ltd**.

Ashnik is responsible for the long-term direction, governance, and maintenance of the project.

## Repository Ownership

The GitHub repository, project infrastructure, and administrative controls are managed by Ashnik Technology Solutions Pvt Ltd through the official Ashnik GitHub organization.

Administrative rights are granted only to authorized representatives of Ashnik.

## Maintainers

Maintainers are individuals appointed by Ashnik to help manage the project.

Maintainers may:
- review pull requests
- triage issues
- contribute code
- propose improvements

Maintainers do **not** own the project.

Maintainer status may be added or revoked by Ashnik at its discretion.

## Contributors

Contributions from the community are welcome.

By submitting code, documentation, or other contributions, contributors agree that their contributions may be distributed under the repository license.

Contributions may be accepted, modified, or declined based on project direction and quality standards.
